📚 is a C++ educational repository created as part of the 42 IT School curriculum 🎓 focusing on C++ basics module 9.

ex00: Bitcoin Exchange 💰₿
Topic: File parsing and data containers (likely using std::map)
What it does: Reads Bitcoin price data from a CSV file and calculates exchange rates based on input values
Key concepts:
CSV file parsing
Data validation
Working with date-value pairs
Exception handling

ex01: RPN (Reverse Polish Notation) 🧮
Topic: Stack-based calculator implementation
What it does: Evaluates mathematical expressions written in Reverse Polish Notation (e.g., "3 4 + 2 *" = 14)
Key concepts:
Stack data structure (likely std::stack)
Expression parsing
Postfix notation evaluation

ex02: PmergeMe 🔀⚡
Topic: Sorting algorithm comparison with different containers
What it does: Implements the merge-insert sort (Ford-Johnson algorithm) using both std::list and std::deque, then compares performance
Key concepts:
Advanced sorting algorithms (merge-insert/Ford-Johnson)
STL containers comparison (list vs deque)
Performance benchmarking
Template programming
All three exercises focus on STL containers 📦 and algorithms 🚀, which is the core theme of C++ Module 09! 💪
